# pdf.hatazrim.com

כלי PDF אישי, חינמי, עברית RTL. הכל רץ בדפדפן - שום קובץ לא עולה לשרת.

כלים: תמונה→PDF, איחוד, פיצול/מחיקת עמודים, סיבוב, כיווץ, PDF→תמונות.

React + Vite + TypeScript, pdf-lib, pdf.js, PWA. פריסה: GitHub Pages (`.github/workflows/deploy.yml`), דומיין דרך `public/CNAME`.

```
npm ci && npm run dev
```
